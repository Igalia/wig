Script Dialog Tests

Tests all four WebKitScriptDialog variants.

Alert (window.alert)

Shows a message. No return value. The dialog should have a single "Close" button.

Confirm (window.confirm)

Asks the user to confirm. Returns true (OK) or false (Cancel). The dialog should have "OK" and "Cancel" buttons.

Prompt (window.prompt)

Asks the user for text input. Returns the entered string, or null if cancelled. The dialog should have a text entry pre-filled with "default value", plus "OK" and "Cancel" buttons.

Before-unload confirm (onbeforeunload)

Fired when navigating away from the page. The dialog should have "Stay" and "Leave" buttons. Clicking "Leave" navigates to about:blank; "Stay" keeps you here.
