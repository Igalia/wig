Input Type Tests

Exercises every HTML <input> type plus the other form controls that render their own popup UI. Types badged native ui open a widget drawn by WebKit or the platform (color chooser, date picker, select popup) — those are the interesting ones for wig, since the popup has to be positioned and sized against the WPE view. File inputs are covered separately in test-choosers.html.
