Window Feature Tests

Exercises WebKitWindowProperties: is-popup, geometry and has-custom-geometry, plus resizeTo(), resizeBy(), moveTo() and moveBy() on an opened window.

What wig should do

A popup gets a window without navigation buttons or tabs, and a read-only address. A window opens as a tab beside this page while Open New Windows in Tabs is on (the default), and as an ordinary browser window otherwise; a tab ignores any size it asked for. When a popup or a window asks for a size, the area the page is shown in is that size, and wig's bars are added around it. The page's size is limited to at least 100×100 and at most the screen's available area. wig can't place windows, so a requested position is reported to the page but not applied.

Open a window

Each row calls window.open() with the features shown. The expected values follow the HTML specification's popup test. The Size column fills in once the window reports back, and it updates live as the window is resized, by the page or by you.

Script-driven resize after load

Opens a 400×300 popup and has the opener resize it to 640×480 one second after it loads. wig should follow, because the page owns that window. Drag a tab into it first and wig should ignore the resize, because the window then belongs to you.
