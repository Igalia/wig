Select Element Tests

Covers what WebKitWebView::show-option-menu can hand over.

Plain list

Third item is pre-selected: the menu should open with it highlighted and focused.

Groups and disabled items

<optgroup> labels should read as headings and not be pickable; their options should be indented. The disabled option should be greyed out and refuse clicks.

value: Apple

Separators

An option with an empty label arrives as a separator item: it should draw as a line, and be neither focusable nor clickable.

value: Above

Long list

60 items, with #45 selected. The menu should cap its height and scroll, opening scrolled to the selected item rather than at the top.

value: Item 45

Wide element

The menu should be at least as wide as the element it drops out of, not just as wide as its longest label.

value: Short

Element removed while the menu is open

Opens the menu, then deletes the <select> two seconds later. WebKit emits WebKitOptionMenu::close and the menu should disappear on its own — no stale popup left hanging over the page.
