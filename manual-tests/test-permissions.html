Permission Tests

Exercises every web API that triggers a permission request. Each section is tagged with whether the underlying WebKitPermissionRequest type is implemented in the WPE WebKit port that wig uses.

Permissions API Query Query

Calls navigator.permissions.query() for every standard permission name. Names that the engine does not recognise reject with a TypeError.

Clipboard Write then Read WPE: no prompt

Writes with navigator.clipboard.writeText() and reads it straight back. WebKit stores the writing origin alongside the contents, so an origin reading back its own text takes the same-origin fast path: this should be granted without a prompt, even while the Clipboard permission is still set to Ask. A prompt appearing here means that fast path is not working.

Not requested yet.

Screen Capture WPE: supported

navigator.mediaDevices.getDisplayMedia() → WebKitUserMediaPermissionRequest with is_for_display_device set. WebKit runs the desktop portal handshake while validating constraints, so the portal's picker appears before the permission request; wig takes that as the answer instead of prompting again. Needs pipewiresrc (gst-plugin-pipewire) to actually produce a stream.

Not requested yet.
